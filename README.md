# PICasso KPI

스파오 우먼·맨, 후아유 WOMEN·MEN의 신상품 대표 썸네일을 주기적으로 수집합니다. 날짜별 현황, 상품 검토, CSV 내보내기를 제공합니다.

## 실행

Python 3.11 이상, Tesseract OCR, curl이 필요합니다.

```sh
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
./setup-models.sh
python app.py
```

기본 포트는 8765입니다. 단일 프로세스로 실행하며, 배포 시 접근 제어가 적용된 내부 서비스로 운영합니다. `PORT`와 `PICASSO_HOST`로 바인딩을 조정할 수 있습니다. 수집 기록과 대상 이미지는 기본적으로 `.local/`에 저장됩니다. 배포 시 `PICASSO_DATA`를 영구 저장소로 지정하세요.

설정에서 매일 자동 수집 시각(한국 시간)을 지정합니다. 해당 시각에 서버가 꺼져 있으면 당일 서버가 켜졌을 때 수집합니다. 수집이 실패하면 화면에서 오류를 확인하고 다시 실행할 수 있습니다.

## 집계 기준

- 스파오는 공홈 화면과 같은 탭별 100개, 후아유는 두 탭의 모든 목록 페이지를 수집합니다. 브랜드 합계는 상품 ID를 중복 제거합니다.
- 대표 썸네일에 얼굴이 보이면 모델 착장컷입니다. 얼굴이 보이지 않는 착장 사진도 상품 단독컷으로 집계합니다. 이미지 수집이나 분석 오류는 미분류로 남습니다.
- 후아유 WOMEN은 설정에 등록한 얼굴과 유사도를 비교합니다. 자동 판정은 OpenCV YuNet과 SFace를 사용합니다. 코사인 유사도 0.45 이상은 유사, 0.32 이상 0.45 미만은 검토 필요입니다. 운영 데이터로 보정할 수 있도록 점수를 CSV에 포함합니다. 유사 분류는 PICasso 적용 여부를 확인하는 지표로 쓰기 전에 별도의 제작 이력 대조가 필요합니다.
- 스파오 품번은 상품명 끝에서 추출합니다. 후아유는 상세 이미지에서 OCR로 추출합니다. 상품 검토 페이지에서 썸네일 분류, 유사도, 품번을 수정할 수 있습니다.
- 첫 실행에는 2026년 11월 24일 검증 샘플 874개를 표시합니다. 새 자동 유사도 집계를 시작하려면 기준 얼굴 이미지를 등록합니다. 샘플에는 일부 상품의 가격과 후아유 품번이 비어 있습니다.

수집에는 공식몰 `www.spao.com`, `whoau.com`과 이미지 호스트 `spao-item.elandrs.com`, `cafe24.poxo.com`, `item-imghub.eland.co.kr`의 HTTPS 접근이 필요합니다. 모델 설치에는 `media.githubusercontent.com` 접근이 필요합니다.

## 호스팅

`python serve.py`로 스케줄러와 Waitress 웹 서버를 함께 실행합니다. 서버를 한 인스턴스로 운영하고, 데이터 디렉터리는 영구 볼륨에 저장합니다. 사내 인증이 적용된 HTTPS 게이트웨이 뒤에 두거나 배포 서비스의 비밀 설정으로 `PICASSO_WEB_USER` 및 `PICASSO_WEB_PASSWORD`를 모두 주입하세요. 로그인은 단일 팀 워크스페이스에 적용됩니다.

컨테이너 배포 시 `Dockerfile`로 빌드합니다. 앱은 8765번 포트를 사용하며 영구 볼륨을 `/data`에 마운트합니다. 컨테이너 사용자 UID 10001이 볼륨에 쓸 수 있어야 합니다. 플랫폼에서 `PORT`를 주입하면 해당 포트를 사용합니다.

### Vercel 프런트엔드

GitHub 저장소를 새 Vercel 프로젝트에 가져옵니다. 루트 디렉터리는 저장소 루트를 사용합니다. Vercel은 대시보드 정적 파일과 API 전달 함수를 호스팅합니다. 수집과 OCR, 자동 일정 및 영구 데이터는 위 컨테이너를 실행하는 별도 서버에서 관리합니다. Vercel 프로젝트의 환경 변수 `PICASSO_BACKEND_URL`에 해당 서버의 HTTPS 주소를 등록합니다. 컨테이너에 팀 로그인 설정을 적용하고, Vercel 프로젝트에도 팀 배포 보호를 적용할 수 있습니다. Vercel을 경유하는 기준 이미지 업로드는 4 MB 이하 파일을 사용하세요.

수집 서버를 연결하면 브라우저에서 초기 집계, 상품 썸네일, 수집 일정 저장, CSV 내보내기를 확인합니다. GitHub의 `main` 변경은 가져온 Vercel 프로젝트에서 자동 배포할 수 있습니다.

### Supabase 저장소

`supabase/migrations/`의 SQL을 프로젝트에 적용하면 수집 작업·상품 테이블과 비공개 이미지 버킷이 생성됩니다. Vercel 서버 환경 변수로 `SUPABASE_URL`과 `SUPABASE_SERVICE_ROLE_KEY`를 설정합니다. 비밀 키는 브라우저에 전달하지 않습니다. 검증 데이터가 초기화된 경우 Vercel 미리보기는 Supabase에 저장된 상품 행을 읽습니다. 수집 서버가 연결되기 전에는 기존 집계 조회만 지원합니다.
